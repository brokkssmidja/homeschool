# homeschool

Practice pages for Inga, published at <https://brokkssmidja.github.io/homeschool/>.

- [Home](index.html) lists subjects.
- [Math](math/) is the math shelf.
- [Times tables](math/calculation/) practices 1 × 1 through 10 × 10.

Progress for the times tables stays in this browser under the key `inga-times-v1`, the same key the earlier copy used. A push to `main` publishes the site with GitHub Pages.
